CampusMate UI App Prototype

How to run:
1. Extract CampusMate_App
3. Open index.html in Chrome or another modern browser.
4. Tap Get Started, enter any non-empty Student ID and password, and explore the screens.

This is a front-end prototype only. It does not store passwords or connect to real college data. Timetable, attendance, assignments, exams and events use sample content. Event registration and password recovery are not connected to a backend.
